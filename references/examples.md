# Examples

Three example boards ship in `../assets/examples/`. Copy their layout and visual style. Don't copy their technologies, numbers or notes into a new board.

| File | Format | What to copy |
| --- | --- | --- |
| `product.excalidraw` | Product | Title and short problem line, the numbered banner, requirements, entities and API beside a large architecture area, deep dives next to the parts they change. |
| `infrastructure.excalidraw` | Infrastructure | Inputs and outputs, a simple first design followed by a deeper one, tradeoffs tied to requirements. |
| `detailed.excalidraw` | Existing system | Parts grouped by owner, labelled links between groups, and a built / partly built / planned legend. |

There's no example file for the Decision format. Use the section list in [frameworks.md](frameworks.md).

The examples have some rough overlaps and half-finished notes. Copy how they're organised, not those flaws.

Default look: white background, dark strokes, hand-drawn text, mint numbered markers, light colour-coded fills with a legend (the colour rules are in SKILL.md, section 4). The Product and Infrastructure examples are mostly uncoloured; colour new boards anyway. Use dark mode only if asked. Text should be readable when zoomed to one section.
